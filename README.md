# 🔍 CartãoLupa (PWA)

App educativo sobre benefícios de cartões de crédito. **Não é aconselhamento financeiro.**

## Rodar localmente
O service worker precisa de HTTP(S), então não funciona abrindo o arquivo direto:
    python -m http.server 8080
Acesse http://localhost:8080

## Deploy (GitHub Pages)
Settings → Pages → Source: `main` / root.

## Privacidade
Não coleta número de cartão, CVV, senha nem dados pessoais. Tudo roda no navegador.
